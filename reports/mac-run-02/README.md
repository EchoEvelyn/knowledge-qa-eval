# 第二阶段 Mac 实测交付

目标是打通知识问答评测完整流程，准确率作为基线观察值，本次不做针对题集的策略优化。

## 证据来源

本目录的 results.json、results.csv、summary.md 为用户上传的 Mac 实际运行与人工评分文件，按原始字节保存。provenance.json 记录导入时间、文件哈希和交叉核对结果。report.html 为从原始 JSON 生成的派生阅读版，不修改原文件。

用户在助手逐题建议下完成评分，评分理由均保留；这不是独立盲评。云端完成归档、核对和工程测试，没有在云端重跑真实模型。

## 环境与配置

- 运行时间（北京时间）：2026-11-05 14:45:13 至 14:46:00。
- 平台：macOS-26.6.2-arm64-arm-64bit；Python 3.11.9；Ollama 0.30.4。
- 模型：qwen3:4b，Q4_K_M；digest `359d7dd4bcdab3d86b87d73ac27966f4dbb9f5efdfcc75d34a8764a09474fae7`。
- 固定配置：top_k=3、temperature=0、seed=42、num_predict=2048、think=false、JSON Schema 输出。
- 题集 20 题（15 有答案，5 无答案），语料 12 条；输入哈希与仓库逐一核对一致。

## 完整流程与验收

固定题集 → FastAPI HTTP 检索 → 本机 Ollama qwen3:4b → 带来源回答或资料不足说明 → 保存片段/原始响应/耗时 → 人工评分 → 汇总报告。

- 能运行：20 题真实模型请求均完成。
- 能保存：JSON、CSV、汇总文件完整且逐题一致。
- 能评分：15 个回答判断、5 个拒答判断及理由全部保存。
- 能复现：数据哈希、模型 digest、Ollama/Python 版本、提示词和参数均有记录；具体回答可能因硬件和版本不同而变化。

新增统一入口的自动启动和浏览器打开操作已在云端以真实 FastAPI + 协议测试桩验证；仍需 Mac 按文档确认一次。这些新增功能未混入本轮原始测量。
