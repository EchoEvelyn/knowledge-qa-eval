## 汇总结果

| 指标 | 结果 | 定义 |
|---|---|---|
| 工程运行 | 20/20成功 | Dify工作流成功且输出通过格式校验 |
| 正确来源文档返回 | 15/15（100%） | 有答案题返回了标注来源的片段 |
| 标注证据覆盖 | 14/15（93.3%） | 正确文档的返回正文覆盖全部证据短语组 |
| 有答案题回答正确 | 13/15（86.7%） | 人工核对事实、要点和引用 |
| 无答案题正确拒答 | 3/5（60%） | 明确资料不足，且没有猜测 |
| 无答案题仍返回片段 | 5/5 | 返回片段不表示存在答案 |
| 评分完成 | 20/20 | 15个回答判定、5个拒答判定 |

证据覆盖是规范化短语规则辅助指标，不是完整语义判断；KB-1等为本次请求内的引用别名，不能当作永久金标ID。永久检索证据以来源、章节、标注短语及保存的正文/哈希定位；当前并未保留Dify原segment_id。

## 错误定位

- D09：正确资料已返回，但模型把“仅允许受管电脑”错误解释为个人电脑可以接入；属于生成事实错误。
- D11：返回了正确网络文档的标题及相关片段，却没有报障所需的错误码、发生时间和客户端版本；证据覆盖失败，模型又输出模板占位文字。
- D16、D18：只重复问题，没有明确说明资料不足，拒答不合格。
- D17、D19、D20：正确说明资料未提供所问事实，拒答通过。
